# موقع عمران الايوب الشخصي

موقع ثابت بسيط وجميل يدعم العربية (RTL) مع وضع ليلي/نهاري وروابط الشبكات الاجتماعية.

## التشغيل محليًا
- افتح الملف `index.html` مباشرة في المتصفح، أو شغّل خادمًا بسيطًا:
  - Python: `python3 -m http.server 8080`
  - Node: `npx serve -l 8080`

## تخصيص الروابط
افتح `index.html` وابحث عن عناصر الروابط داخل القسم ذي الصنف `links`، ثم غيّر `USERNAME` إلى اسم مستخدمك/رابطك الفعلي:
- إنستغرام: `https://instagram.com/USERNAME`
- يوتيوب: `https://youtube.com/@USERNAME`
- تيك توك: `https://tiktok.com/@USERNAME`
- فيسبوك: `https://facebook.com/USERNAME`
- تليجرام: `https://t.me/USERNAME`
- REDZ: استبدل `href="#"` بالرابط الصحيح لمنصتك على REDZ

يمكنك أيضًا تعديل الاسم والنص التعريفي من العناوين في `index.html`.

## التخصيص المتقدم
- الألوان والتصميم في `assets/styles.css`.
- وظائف الواجهة (زر الوضع الليلي/النهاري) في `assets/main.js`.

## النشر
- ارفع الملفات كما هي إلى أي استضافة ملفات ثابتة (مثل GitHub Pages أو Netlify أو Vercel).

> إن رغبت بإضافة أقسام إضافية (سيرة ذاتية، معرض أعمال، نموذج مراسلة)، أعطني التفاصيل وسأقوم بتوسيع الموقع.
